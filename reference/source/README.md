# HUFF SOURCE — Quick Reference

One screenshot, then its 13 control definitions. Based on the approved VISTA SDS-001 annotation framework. Original screenshot unmodified.

## Files

- `index.html`: standalone entry point (requires `assets/` beside it).
- `source.json`: source control definitions/target coordinates for editing.
- `assets/source-original.png`: exact uploaded UI screenshot.
- `SOURCE_Quick_Reference.pdf`: separately exported landscape PDF.
- `desktop-preview.png`, `mobile-preview.png`, `pdf-preview.png`: verification previews.

Open `index.html` with its `assets/` folder alongside; use Edit text / Export JSON / Import JSON / Export PDF as provided by the framework. PDF output is an archival convenience and not a replacement for HTML curation.
