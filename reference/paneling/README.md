# PANELING — SDS-001 Quick Reference

This package contains the PANELING quick-reference HTML, JSON, original unmodified BANDS and FIELD screenshots, exported PDF and render previews.

## Corrections
- Field Zoom (40) arrow now targets the first-row ZOOM slider.
- Field XY Motion (46) arrow now targets the second-row XY MOTION slider.
- PDF exported in A2 landscape (two pages; Bands and Field separately) to preserve readable descriptions and UI proportions.
- Approved small mode captions above diagrams are retained only for PANELING.

## Usage
Extract the entire folder; open `index.html` with the `assets` folder alongside it. The document retains drag-to-edit callouts and JSON import/export. Use the browser print dialog to choose additional landscape paper sizes; exported PDF is a verified A2 landscape sample.
