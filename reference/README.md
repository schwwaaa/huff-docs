# HUFF Quick Reference Library — Public Website

Publish this folder as a static GitHub Pages site. Open `index.html` to browse references.

All 11 reference pages are **read-only**. They do not include editing/import/export controls, draggable SVG annotations, or event handlers that modify callouts. Layout, original screenshots, definitions, and logo links are retained.

Original editable files are supplied in a separate authoring archive and are **not inside this public website ZIP**. Keep that archive private; do not publish it.

Static websites cannot prevent someone from altering their *own browser display* using developer tools, but those local changes cannot modify the published files on GitHub Pages without repository write access.

The `schwwaaa-logo.png` asset referenced by the index must be added at the website root if you wish it to appear.
